## 核心术语与缩写

| 缩写 | 全称 | 含义 |
|---|---|---|
| AIL / AIS | Always In Long / Short | 单边做多/做空：市场当前方向的明确倾向，只应考虑顺此方向交易 |
| BO | Breakout | 突破：价格超越支撑或阻力位 |
| PB | Pullback | 回调/反弹：趋势中的暂时停顿或反向运动 |
| TR / TTR | Trading Range / Tight TR | 震荡区间 / 窄震荡区间 |
| MTR | Major Trend Reversal | 大反转：趋势发生根本性改变 |
| EMA20 | 20-period EMA | 20周期指数移动平均线，本方法论唯一默认均线 |
| H1/H2/H3 | High 1/2/3 | 上涨趋势中第一次/二次/三次尝试恢复上涨的信号 |
| L1/L2/L3 | Low 1/2/3 | 下降趋势中第一次/二次/三次尝试恢复下跌的信号 |
| TBTL | Ten Bars, Two Legs | 至少10根K线、两段式走势的调整，反转后的最低预期目标 |
| MM | Measured Move | 测量移动：基于波段/区间/突破高度的等距目标位 |
| R | Risk | 初始风险（止损距离） |

**基本单位**：Tick（期货最小变动单位）、Pip（外汇最小变动单位）。
**层级**：腿(Leg，任意一段移动) < 波段(Swing，10-20根K线、幅度为剥头皮利润3-5倍) < 趋势(Trend，占据屏幕大部分；一屏出现3个以上"趋势"说明实为宽幅震荡)。

## K线与图表基础

### K线二分法（结合背景判断）
- **趋势K线 (Trend Bar)**：实体占K线总高度 50% 以上，影线短 → 一方力量明确。
- **震荡K线/十字星 (Trading Range Bar)**：实体小于总高度 50%，常有长影线 → 多空平衡、犹豫。
- **背景修正**：强趋势中的小实体K线也算趋势K线；横盘中的大实体K线也算震荡K线。**每一根长影线都是一次在更小时间周期上失败的突破尝试。**

### 市场本质
- 市场目的是促成交易、最大化成交量，因此不断寻找"公平价格"，上下移动以探测边界。
- **约 80% 的时间市场处于震荡区间**，趋势是例外；震荡中多数突破尝试失败。
- 价格行为是机构/算法集体行为的"足迹"，**不存在噪音**——每个波动背后都有逻辑。
- **价格即真理**：不根据新闻内容预测，只看市场对新闻的反应；"涨就是利好，跌就是利空"。

### 指标与成交量的态度
- 强烈不建议依赖成交量、背离、震荡指标：在强趋势中背离会频繁出现并误导逆势交易（"千刀万剐式亏损"）。
- 移除指标、只看价格行为：结构（突破失败、双顶/底、通道）一目了然。
- 强信号K线本身就蕴含了成交量信息。

### 职业交易者真正关注的两大核心
1. **背景 (Context)**：图表左侧的一切，主要是支撑与阻力（前期高低点、趋势线、通道、均线）。
2. **动能 (Momentum)**：趋势强度，通过K线实体大小、连续性、高低点推进判断。

## 信号K线与K线模式

### 信号K线 vs 入场K线
- **信号K线 (Signal Bar)**：让你决定下单的K线。
- **入场K线 (Entry Bar)**：订单实际成交的K线；强势突破时可同一根（市价/收盘价入场）。
- **核心原则：背景 > 信号K线**。好信号+坏背景=坏交易；坏信号+好背景=好交易（如阴线做多信号出现在可靠形态末端）。

### 反转K线 (Reversal Bar)
- **多头反转**：收盘价必须在自身范围中点以上（不强制阳线，阳线更佳）。理想形态：实体大、下影线占1/3至一半、收盘近最高。
- **空头反转**：收盘价必须在自身范围中点以下（不强制阴线，阴线更佳）。
- **入场方式**：信号K线高/低点上方/下方一格挂突破单。
- **强趋势中的首次反转大概率失败**（只形成旗形），等待第二次信号（双顶/双底）更稳妥。

### 孕线与吞噬线
- **孕线 (Inside Bar, i)**：高低点完全被前一根K线包含 → 停顿/收缩，是小震荡区间。
- **吞噬线 (Outside Bar, o)**：高低点完全覆盖前一根K线 → 波动扩大、潜在反转。**强空头吞噬线**常出现在突破失败后，代表控制权转移，是高概率信号。
- **突破模式组合**：`ii`（连续孕线）、`ioi`（内-外-内）→ 在小周期上是收敛三角形，预示突破/反转即将发生。最后一根是强阳/阴线则顺势突破成功率更高；趋势末期出现则是竭尽/末端旗形警告。

### 多K反转
- 两根或多根K线构成的反转形态，在更高时间周期上简化为单根标准反转K线。按单K反转同等交易，不必拘泥形态。

## 回调与数K线（H/L计数体系）

### 回调定义
- 上涨趋势回调：某根K线低点低于前一根K线低点。下降趋势反弹：某根K线高点高于前一根K线高点。
- **隐含回调**：上涨中的阴线或长上影K线（即使未创新低）＝小周期上已发生回调，同样是入场机会。

### 数K线（系统化入场）
- 上涨趋势：恢复上涨的尝试依次为 **高1(H1)、高2(H2)、高3(H3)**；下降趋势：**低1(L1)、低2(L2)、低3(L3)**。
- **所有双底 = 高2买入形态；所有双顶 = 低2卖出形态；所有三推楔形 = 高3/低3**。
- 计数到 4-5 次以上：原趋势大概率已结束，转震荡或反向，停止原方向计数。
- 强趋势中不要数逆势信号（如强下跌中不数高1/2/3），将所有反弹视为旗形，专注顺势 L1/L2。

### 为何高2/低2 是高概率信号
- 逆势交易者能容忍一次不利运动（H1/L1），第二次（H2/L2）时放弃并回补离场 → 与顺势入场者形成同向合力，供需失衡。
- **复合反转 (H4/L4)**：第一次筑顶/底失败后，第二次复合型尝试成功率更高；小周期复杂的 H4 在大周期常简化为清晰的 H2/L2。

### 关键水平与拐点
- **50% 回调**：趋势腿 50% 位置，顺势方与逆势方盈亏比相同(1:1)，但顺势方胜率更高(约60% vs 40%)，是机构青睐的数学优势区，常用限价单。
- **重要拐点 (Major Swing Point)**：其后跟随了强劲突破并创新高/新低的起涨/起跌点 → 顺势止损应放在它之外。
- **次要拐点 (Minor Swing Point)**：其后没有强突破 → 突破它不代表趋势结束，把止损放它之下会被扫掉。

### 回调演变为震荡（20根K线法则）
- 回调/反弹持续 **超过20根K线** → 演变为震荡区间，趋势延续与反转概率变为 **50/50**，进入"突破模式"。止损位过远也促使机构分批止盈，加剧回调。

## 买卖压力

- **买压迹象**：更多/更大的阳线、连续阳线、阳线收在高位、K线底部有下影线、上涨窄通道、突破前高、制造缺口、阳线体积增大。
- **卖压迹象**：对称反向（更多/更大阴线、连续阴线、收在低位、长上影、下降窄通道、跌破前低、缺口、阴线体积增大）。
- **震荡区间内评估突破方向**：阳线增多+体积增大+向上缺口+更高高/低点 → 向上突破概率增加；反之向下。
- **通道内压力评估**：上涨通道关注卖压是否增强（阴线增多/变大、阳线跟随不佳、回调加深、重叠增多）→ 通道可能被向下跌破；下降通道看买压对称判断。
- 显著买卖压力反映机构共识，增加趋势持续概率。

## 缺口

### 广义定义（Al Brooks 特有）
- **缺口 = 当前价格与任何重要前期支撑/阻力之间的空隙**（前期高/低点、K线开收盘价、均线、趋势线等）。缺口代表强动能：市场认为当前价格"错误"。
- **缺口 ≈ 趋势K线**：一根大趋势K线与跳空缺口在交易上等价，用同一套逻辑分析。

### 传统缺口类型
| 类型 | 位置 | 含义 |
|---|---|---|
| 突破缺口 (Breakaway) | 新趋势开始 | 事后才能确认 |
| 测量缺口 (Measuring) | 趋势中途 | 标志趋势走了一半，可算 MM 目标（起点到缺口的距离翻倍） |
| 竭尽缺口 (Exhaustion) | 趋势末期（20-40根K线后） | 通常是最大K线，很快被回补 → 趋势衰竭 |
| 普通缺口 (Common) | 震荡区间内 | 无预测价值，迅速回补 |

### 其他缺口变体
- **均线缺口K线 (MA Gap Bar)**：K线整体（含影线）完全位于 EMA20 另一侧 → 逆势力量增强的第一个信号；原趋势下一次恢复运动大概率是最后一段，之后警惕大反转尝试（反转尝试成功率约40%）。
- **微型缺口**：趋势K线后一根K线未能触及前高/低点 → 趋势极强；被填补则趋势减弱。
- **跳空K线**：开盘价与前一收盘价之间有缺口 → 交易者急切；趋势末期顺势跳空立即反转 = 衰竭信号。
- **实体缺口/负缺口**：影线重叠但实体不重叠 → 趋势仍强（弱于真缺口），在线型图上显示为真缺口。

### 缺口与趋势强度（试金石）
- **缺口保持开放（未被填补）＝几乎没有回调的趋势＝强趋势**：坚决顺势，不要逆势。
- **缺口被填补＝阶梯模式 (Stepping Pattern)＝趋势减弱**：逆势剥头皮变得可行，顺势需谨慎；阶梯模式常预示从窄通道演变为宽通道/震荡，最终反转概率大增。

## 市场周期与市场状态

### 周期四阶段（突破 → 通道 → 震荡 → 新突破）
1. **突破 (Breakout)**：最强劲形态，大实体趋势K线、无回调。只顺势，胜率高但止损远（高风险）。
2. **窄通道 (Narrow Channel)**：趋势仍强，回调1-3根且浅。只顺势。
3. **宽通道 (Wide Channel)**：回调5-20根且深，双向机会。顺势做波段，逆势可剥头皮。
4. **震荡区间 (Trading Range)**：≥20根K线横盘，80%突破失败，50/50，高抛低吸剥头皮。

### 市场两种状态与惯性
- 任何时候市场只有两种状态：**趋势** 或 **震荡区间**。看不懂时默认震荡。
- **80% 法则（惯性）**：趋势中 80% 的反转尝试失败（演变成旗形）；震荡中 80% 的突破尝试失败。

### 二元决策框架
趋势还是震荡？→ 若是趋势：突破还是通道？→ 若是通道：宽还是窄？→ 若是反转：大反转还是小反转？
- 窄通道/突破：只做单边；宽通道/震荡：可双边（高抛低吸）。
- 第一次反转尝试在强趋势后大概率是**小反转**，做剥头皮即可。

### 重要 vs 次要高低点
- **重要高/低点**：其后跟随强劲突破并创新高/新低 → 止损放其外；突破它 = 趋势前提失效（大概率转震荡）。
- **次要高/低点**：其后无强突破 → 突破不意味着趋势结束。

## Always In 单边趋势

### 核心概念
- **定义**：市场方向性极强，交易者只应考虑一个方向。"如果你必须时刻持仓，会选哪个方向？"——这个方向就是 Always In 方向。
- **常见形态：急速变通道 (Spike and Channel)**：强劲初始突破（尖峰）+ 平缓通道延续。
- **入场**：可以基于任何理由顺势入场（回调、突破前高/低、强K线收盘、市价）——顺趋势时任何信号可靠性都增加。
- **止损**：初始止损放整个趋势的起涨/起跌点（重要波段点）之外 → 通常较远，**必须小仓位**；创新高/新低后移动到最近的重要高/低点之后。
- **波段优于剥头皮**：强趋势中一次波段利润远超多次剥头皮总和，且决策更少、管理更简单。

### 启动信号（"惊喜"）
- 单根超级K线 / 连续两根强K线 / 3-6根连续同向小K线（累积等效一根大K线）。
- 心理：被套逆势者止损（离场）、踏空顺势者追入（入场）→ 双重力量推动趋势。

### 趋势终结确认
- 弱反弹信号：缺乏连续强阳线、长上影 → 只是熊旗。
- 可靠反转需要大级别形态：**低点抬高的大反转 (HL MTR)、楔形牛旗、头肩底**等，且需强力突破+良好跟随确认。
- 小逆势波动不要离场；确认大反转形态后才离场。

## 80% 法则与关键概率

| 概率 | 情境 |
|---|---|
| 80% | 震荡区间内突破尝试失败 |
| 80% | 强趋势中反转尝试失败 |
| 75% | 上涨通道（熊旗）最终被向下跌破 / 下降通道（牛旗）被向上突破 |
| 75% | 楔形（倾斜三角）向倾斜相反方向突破 |
| 70% | 通道突破在约5根K线内失败并反转（在能容纳通道的最大周期上应用） |
| 60% | 趋势中顺势方向概率（单边趋势中先向趋势方向移动1单位概率≥60%） |
| 60% | 成熟趋势末期大突破为竭尽型缺口（而非测量型） |
| 60% | 强势突破后到达顺势 MM 目标 |
| 40% | 大反转形态成功演变为反向波段 |
| 50/50 | 持续>20根K线的震荡区间（突破模式）向上/向下 |
| 50/50 | 止损被触发后的突破：成功或失败各半（依K线强度调整至60%） |
| 90% | 市场处于通道/震荡的时间比例（只有10%是强势突破） |
| 40-60% | 震荡/通道中任何方向的胜率 |

## 外汇与图表设置

### 外汇市场要点
- 去中心化、24小时（周日-周五）、无官方收盘价、无可靠成交量数据（平台数据仅占<1%）。
- **点 (Pip)**：多数货币对第4位小数；日元对第2位。点值速算：10万单位标准手 1点≈10美元。
- **成本**：点差是直接成本；佣金平台+小点差通常总成本更低。选择规模大信誉好的平台。
- **杠杆**：双刃剑，勿用最大杠杆；过度杠杆是爆仓主因。
- **图表近似性**：不同平台K线略有差异（数据源、出价/要价/中点图），是近似指导而非绝对精确记录。
- 个人交易者应**忽略基本面**，完全依据图表价格行为决策。

### Al Brooks 图表设置
- 主图：**5分钟图**（只显示常规交易时段），叠加 **5分钟 EMA20 + 60分钟 EMA20**（蓝虚线），重视15分钟 EMA20。
- 近似：5分钟图上模拟 60分钟 EMA20 → 用 EMA220；模拟 15分钟 EMA20 → 用 EMA50。
- 日线看 EMA20；股票加 SMA50/100/150/200；外汇 SMA 重要性较低。
- 无干扰环境（关新闻、电话、"专家"）；交易是零和博弈，目标是转移他人资金到自己账户。

### 情绪作为交易雷达
- **困惑/失望 = 震荡区间** → 高抛低吸、剥头皮。
- **紧迫感（觉得涨跌太快想等回调） = 强趋势** → 立即市价入场（小仓位），不要等回调。
- **恐惧**：用"不在乎仓位"的小仓位消除情绪干扰；**贪婪**：基于数学逻辑止盈。
