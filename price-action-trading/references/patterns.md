## 支撑与阻力

### 定义与来源
- 支撑：下方买盘预期强于卖盘的价位；阻力：上方卖盘预期强于买盘的价位。价格行为主要由支撑/阻力驱动，而非新闻。
- **完整来源清单**：趋势线/通道线、前期高低点、MM目标位、均线（EMA20动态支撑/阻力，股票看SMA50/100/150/200）、整数关口、入场K线/信号K线高低点、入场价格本身、波段收盘价、剥头皮目标位、昨日/今日高低开收、周/月/年线关键价位、日内中枢点、50%回调、期权行权价（整数关口强化）。

### 关键原则
- **80% 法则**：强趋势中80%概率不会在明显支撑/阻力位停止而是突破它（顺势突破交易）；震荡区间中80%测试支撑/阻力会失败（高抛低吸）。
- **整数关口**：心理+订单集中+期权行权价 → 磁铁效应；ES看10点/百点整数，股票看整百，外汇看0.xx00/百点关口。
- **50% 回调**：Al Brooks 认为最重要回调位，上涨回调至前段涨幅50%处是买入区，下跌反弹至50%处是卖出区。
- **突破回测**：突破后常回测突破点；原阻力变支撑、原支撑变阻力。回测并出现确认信号（反转K线）时顺势入场。
- **失败的突破 = 强反向信号**：多头陷阱（上破后回落）/空头陷阱（下破后反弹）→ 被困者止损加剧反向运动。如向上突破20根K线区间失败→常跌至区间低点。
- **收盘价效应**：强趋势后首次回调中，前期"买收盘"多头在前期最高收盘价附近卖出平仓 → 该价位成阻力（对称：最低收盘价成支撑）。
- **磁铁效应与真空效应**：价格接近支撑/阻力时加速（真空），触及后突然反转。
- **共振 (Confluence)**：多种支撑/阻力（前低+50%回调+EMA20+整数）汇聚 → 强度大增，高胜率区域。

## 测量移动 MM（目标测算）

### 三种主要 MM 算法
1. **第一段 = 第二段 (Leg1 = Leg2)**：初始趋势运动（Leg1）经暂停（回调/旗形）后，第二段幅度与第一段大致相等。适用于强突破后、趋势回调后、嵌套结构、急速变通道（Spike 为第一段）。
2. **基于震荡区间高度**：突破区间后至少移动相当于区间本身高度的距离（从突破点向外投射）。突破后即使影线重叠、只要实体不重叠（实体缺口），仍有约60%概率到达目标。
3. **基于突破K线/突破波段高度**：
   - 顺势 MM（约60%概率到达）：测量突破波段高度，从终点同向翻倍。
   - 反向 MM（约40%概率）：突破失败后向反方向投射相同高度（跌破突破波段起点时警惕）。

### 应用原则
- MM 目标是**预期区域**而非精确点位，是强支撑/阻力（"磁铁"），机构在此止盈 → 常引发停滞/回调/反转。
- 价格轻松突破第一个 MM → 趋势强，看下一个更大级别的 MM。
- 多个 MM 目标汇聚（区间高度+突破高度+Leg1=Leg2）→ 区域重要性大增。
- 灵活确认起点/终点；关注市场在目标位附近的实际反应。形态高度→颈线翻倍是常见反转目标。

## 反转与小反转

### 定义与分类
- **广义反转**：趋势转反向趋势、趋势转震荡、震荡突破成趋势，都算反转。所有反转始于某种突破。
- **小反转 (Minor)**：持续3-10根K线，不会改变原趋势，多数演变成旗形或震荡 → 顺势者加仓机会，逆势者仅剥头皮。
- **大反转 (Major)**：需要较多K线（如20根+）确认，目标是形成反向新趋势。
- 反转通常先经历震荡/盘整（双重顶/底、头肩结构），纯 V 形反转少见。

### 反转交易的核心数字
- **大反转成功率约 40%**：60% 会演变为震荡或原趋势恢复（结果多为小盈小亏打平）。
- **最低盈亏比 2:1**：大反转波段交易目标至少为初始风险的2倍（胜率40% + 盈亏比2:1 = 正期望）。
- **最低目标 TBTL**：至少两段、各约10根K线的反向走势。
- **第一次反转尝试**：强趋势后大概率失败（小反转）；**第二次尝试（双底/双顶结构）** 成功率高。

### 入场权衡
- **早期入场**（反转信号刚出现）：止损近、盈亏比极高、胜率约40%。
- **确认后入场**（强突破K线+良好跟随）：胜率>60%、止损远、盈亏比差。
- 新手误区：只看到"低风险高回报"忽视低胜率 → 频繁低概率反转尝试导致持续亏损。
- **买卖压力是关键**：强卖压=大实体阴线+连续阴线+短下影+跌破关键支撑；强买压对称。信号K线体积远小于主导趋势K线 → 反转可靠性低。
- **嵌套结构**：小级别形态（小楔形/小双底/小头肩）在大级别关键位（前高/低、50%回调、趋势线、MM）形成 → 信号共振增强。
- 杯柄形态（Cup with Handle）：U形杯+杯沿上方的小幅回调（柄），突破柄上轨/杯右沿为买入信号，长周期+放量更可靠。

## 大趋势反转 (MTR)

### 构成要素
- **需要时间**：筑顶/筑底通常>20根K线，几根K线的调整只是小反转/中继旗形。
- **前提**：始于一次有力的趋势线突破，随后原趋势尝试恢复但失败。
- **逆势方力量证明**：价格（急促大幅逆势运动：连续大阴/阳线）+ 时间（>10-20根K线阻止原趋势恢复）。

### 常见形态
- **高点降低的大反转 (LH MTR)**：趋势线突破后未能创新高 → 更低高点（多为双顶）。跌破颈线/关键支撑确认。
- **高点抬高的大反转 (HH MTR)**：创新高后多头耗尽立即大幅反转（多头陷阱），常为楔形顶/扩张三角形。多头"放弃K线"（收盘在低位的大阴线）确认。
- **低点抬高的大反转 (HL MTR)**：趋势线突破+强反弹后未能创新低 → 更高低点。筑底需要信服力的买压证据（强劲反弹5-10根K线、触及均线、均线缺口K线）。
- **低点降低的大反转 (LL MTR)**：创新低后立即大幅反转（空头陷阱），常为楔形底。
- 头肩顶/底是大型 MTR 组合。**绝大多数顶部是双顶变体，绝大多数底部是双底变体**（需要对极点进行第二次测试）。

### 均线缺口K线 (MA Gap Bar)
- K线整体（含影线）完全位于 EMA20 另一侧 → 逆势力量增强第一个信号；原趋势下一次恢复运动大概率是最后一段，之后警惕 MTR。

### 失败的反转
- MTR 约60%失败。**失败的反转是极可靠的顺势信号**：逆势者止损 + 顺势者入场双重力量，预期沿原趋势至少两段式运动，可用形态高度算 MM。

## 末端旗形 (Final Flag)

### 识别特征
- 趋势中的最后一个旗形：突破后失败，原趋势终结，转为震荡或反向趋势。本质是一个**震荡区间**。
- **趋势成熟度**：原趋势已持续很久（20根或更多K线）。
- **长时间横盘**：回调持续超10-20根K线，演变成水平震荡区间/三角形 → 50/50状态。
- **衰竭迹象**：一系列高潮（连续大K线）但缺乏回调；出现楔形（三推）；强趋势线突破；临近重要支撑/阻力（前高/低、通道线、MM目标）。
- **微型末端旗形**：高潮后极小的旗形（单根十字星、1-3根K线）→ 极可能是末端旗形。
- **ii 末端旗形**：连续两根孕线在小周期=三角形，趋势后期出现 → 首破50%失败。

### 交易含义
- 识别末端旗形后：顺势入场只做快速获利了结；准备反转交易（等待第二次入场信号或大反转形态）；利用失败突破（巨大反向K线）入场。
- 心理机制：弱手在最后高潮被迫止损离场，强趋势方获利离场，强逆势方开始建仓 → 力量失衡导致反转。
- 高潮后强趋势方至少等10-20根K线才重新入场 → 为逆势方创造空间。

## 楔形 (Wedge)

### 定义
- 一个方向上的**3次或更多推动**的价格结构，本质是倾斜的收敛三角形。通常5段（3推+2回调）。
- 反转形态：楔形顶（上涨末端三推向上）、楔形底（下跌末端三推向下）。持续形态：楔形熊旗（下降趋势中的三推反弹）、楔形牛旗（上涨趋势中的三推回调）。
- 不必完美：识别"三次尝试失败"的本质比精确画线更重要。画线优先选能产生"凸刺"的画法。

### 概率
- **上升楔形/通道 = 熊旗：约75%概率被向下或横向突破**；**下降楔形/通道 = 牛旗：约75%概率被向上突破**；水平三角形 50/50，首次突破50%失败。
- 楔形突破（75%事件）仅表示原通道结束，可能进入震荡而非立即反向趋势；25%的加速突破会引发极强趋势。

### 心理与交易
- 楔形= FOMO 拥挤交易瓦解：被套内（止损离场）与被套外（错过者追入）双重力量 → 反转后至少两段式行情。
- **缩减楔形/失败的第三推**：第三推未能创新高/新低（短缺）→ 仍是有效的三推失败模式，但首信号胜率较低，等第二入场点。
- **突破双顶/双底失败**：第三次突破双顶高点失败 → 功能等同楔形顶（三重顶/底原理）。
- **伪楔形**：震荡区间内的三推结构不是反转信号，仅剥头皮。
- **无效楔形（陷阱）**：强趋势窄通道（高周期上只是一两根强K线）、波段间有缺口（无重叠）、缺乏反向力量、结构不对称 → 放弃逆势，80%逆势尝试失败。强趋势中一次强力突破后**重置计数**（视为新趋势第1推）。
- **抛物线楔形**：斜率不断增加的楔形（一系列连续高潮），最终突破通道线后反转。早期入场胜率低盈亏比好；确认后入场胜率高止损远。
- **失败的楔形突破（50/50）**：反转楔形后首破失败、突破楔形极值（触发止损）→ 50%继续到MM / 50%形成"失败的突破"二次反转。第二次入场信号更可靠。
- **楔形旗形反向突破**：本应延续趋势的楔形旗形却反向突破 → 意外行情，至少两段式，反向目标=原形态高度MM。
- **水平的"小突破之后的小突破"楔形**：被反向强突破后到达 MM 概率至少60%。

## 双顶与双底

### 本质
- 市场对前期高/低点的**测试**：第二次到达该区域时买/卖盘再次出现则确认支撑/阻力有效。很少完美（第二个点可略高/略低）。
- **等价关系**：所有双顶=低2做空信号；所有双底=高2做多信号；双顶熊旗/双底牛旗=趋势内旗形（顺势高胜率）；大反转（趋势末端大规模形态）。

### 反转机制（心理）
- 双顶：第一高点买入的多头被套，第二次冲高失败 → 失望卖出（止损）+ 自信空头开仓 → 合卖压反转。双底对称（被套空头回补+多头入场）。

### 交易与应用
- **MM 目标**：形态高度（极值到颈线）从突破点向外投射，是强止盈位。适用于成功反转与失败反转（失败双顶上破=强烈看涨）。
- **失败的双顶/双底是强信号**：本应反转却向原趋势方向突破 → 强烈顺势信号（被困逆势者止损+顺势者入场）。
- **小双顶/小双底（2-5根K线）**：作为大双顶/双底的第二个测试点时增强大形态可靠性（嵌套结构）。
- 回调/旗形持续**超过20根K线** → 转为中性震荡区间（50/50），停止假定原趋势恢复；区间内假突破后常引发向另一侧的强力运动。
- 三重顶/底与三角形：三次尝试失败=更强反转信号；三角形=含双顶双底的震荡区间（突破模式）。

## 三角形 (Triangle)

### 定义与识别
- 至少3次同向推动（另一方向至少2次）的横盘震荡区间，至少5段。无需精确画线，核心是"窄幅震荡+多空平衡"。
- 收敛三角（高点降低+低点抬高）、上升/下降三角（一边水平）、扩张三角（喇叭形，至少5次反转，核心行为=突破失败：新高后反转回区间另一端）。
- 连续孕线（ii、iii）在小周期=小型收敛三角形。

### 概率与交易
- **水平三角形：上/下突破 50/50；首次突破 50% 失败**（价格回到区间内）。
- **20根K线法则**：<20根且趋势中=延续旗形（顺势概率更高）；>20根=中性突破模式（50/50）。
- **楔形是倾斜的三角形**：~75%向倾斜反方向突破（上升楔形向下、下降楔形向上）。
- **末端旗形**：成熟趋势末期的三角形 → 突破是竭尽性的，失败概率高，失败后常回测三角形顶点并可能反转。
- **扩张三角形**：大而对称=主反转信号（LL MTR 底 / HH MTR 顶）；趋势中=持续旗形；交易策略=衰竭突破（新高卖、新低买），目标区间另一端或 MM。
- **形态质量**：清晰对称的形态成功率更高；不对称、混乱的"丑陋"形态不可靠（算法会忽略）→ 不交易糟糕形态。嵌套结构增强可靠性。

## 头肩形态

### 本质
- 头肩顶 = 高点降低的大反转（LH MTR）；头肩底 = 低点抬高的大反转（HL MTR）。本质是一个**震荡区间**（趋势向另一状态过渡）。
- **前提**：需要先有一次强力的趋势线突破；随后原趋势尝试恢复失败形成右肩（核心信号）。左肩非必需。
- **关键认知：绝大多数头肩形态只是小反转**（演变成震荡/复杂旗形而非新趋势）。缺乏趋势线突破前提、规模过小 → 小反转。

### 交易策略
- 三种入场权衡：极值点早期入场（胜率约40%、盈亏比极佳）；右肩反转信号标准入场（均衡）；颈线强突破+跟随确认入场（胜率高、止损远）。
- 颈线是区间边界区域而非精确线（多种画法都接近）。
- 头肩=震荡区间 → 传统颈线突破胜率不高（约40%形成波段）；**区间内交易更优**：右肩反弹失败出现反转信号时做空。
- **突破失败是强信号**：颈线突破失败反转（多头视为牛旗/高2/双底/楔形牛旗，空头视为头肩）→ 套牢突破者，是强反向信号。
- **50/50 法则**：合理止损被触发（突破）后，突破 50% 成功/50% 失败；强突破K线+良好跟随 → 成功概率升至60%+；紧接十字星/反向K线 → 突破正在失败。
- 三推视角：头肩（左肩-头-右肩）可看作三推楔形变体。

## 圆顶与圆底

### 核心观点
- **名称不重要，行为是关键**：圆顶/圆底本质是趋势停滞后形成的**震荡区间**。Al Brooks 更倾向用头肩、MTR、三角形等精确术语。
- 交易重点：理解市场已从趋势转为多空平衡，识别具体信号，而非纠结命名。

### 无尽的回调/反弹 (Endless Pullback)
- 回调/反弹持续**超过20根K线** → 演变成反向窄通道或震荡区间，市场进入 50/50 突破模式，原趋势优势消失。
- 交易：等待强突破K线+良好跟随的确认信号，勿盲目顺势。

### 派发与吸筹（心理）
- 圆顶（派发）：强空头逢反弹积极卖出（押注上涨失败），强多头停止追涨 → 买方只剩弱多头 → 向下突破。
- 圆底（吸筹）：强多头逢低买入（押注下跌失败），空头发现无法持续下跌而放弃 → 向上突破。

## 高潮 (Climax)

### 定义与区分
- 任何大趋势K线（或系列）既是突破也是高潮。**突破**＝趋势早期的加速（新趋势开始）；**高潮**＝趋势后期（>20根K线后）的加速（衰竭信号）。
- 形态：单根巨大K线，或一系列连续趋势K线（无回调微通道，高周期上=1-2根突破K线）。
- **高潮后市场通常暂停进入震荡**，原趋势延续与反转概率各约50%（真正V形反转是例外）。

### 竭尽型缺口 vs 测量型缺口
| | 竭尽型 (Exhaustion) | 测量型 (Measuring) |
|---|---|---|
| 背景 | 成熟趋势末端（>20-50根K线） | 突破长震荡区间/趋势早期 |
| K线 | 整个趋势中体积最大 | 强但非最大 |
| 后续 | 很快被回补，进入震荡/反转 | 回调不回补，继续同向运动 |
| 概率 | 约60%是竭尽型 | 约60%到达MM目标 |
| 交易 | 顺势者止盈；强反转信号后逆势，第一目标=高潮起涨/跌点 | 顺势入场/加仓，目标MM |

### 心理机制
- **惊喜K线/礼物K线**：趋势末期突然出现的超大K线。强顺势方=获利了结；强逆势方=建仓；弱逆势方=恐慌止损（助推K线）；弱顺势方=FOMO追高/杀跌买在顶底 → 买/卖压失衡，趋势难以为继。
- **连续高潮**：一系列趋势K线接连出现（抛物线楔形），弱空头被轧（止损回补助推上涨）、弱多头追高 → 强多头止盈+强空头建仓 → 买盘枯竭反转。
- **抛售高潮的期权做市商因素**：做市商为对冲看跌期权Gamma风险大量做空，加剧抛售高潮 → 高潮体现的空头情绪可能被夸大；买高潮强度通常弱于卖高潮。
- 高潮结束信号：十字星、反向K线、实体缩小K线出现。

### 高潮后策略
- **TBTL 法则**：反转后强顺势方至少等待 **10根K线、两段式** 的调整才会重新入场。
- **20根K线规则**：高潮后盘整>20根K线 → 突破模式 50/50。
- **第一目标**：反转后第一天然目标是高潮的**起涨/起跌点**；测试起点常形成双顶/双底，其突破方向决定下一步主要方向。
- **真空测试**：价格以强突破进入已知支撑/阻力区 → 不可持续，反转概率极高。
- **共振**：高潮同时发生在多个关键位（通道线、前高/低、MM、楔形）→ 竭尽概率大增。
- **连续高潮形成的通道/楔形底**：本质牛旗75%向上突破（路径一：25%向下强破→MM级别新下跌；路径二：75%竭尽反转→至少两段10根K线反弹）。
- **大涨大跌 = 大困惑**：急剧双向运动后市场极大概率进入横盘震荡（至少5-10根K线）→ 高抛低吸而非追趋势。
