## 四、翻译与结构约定

- **术语**：英文缩写一律保留原文（SMT、SSMT、PSP、CiSD、CiC、DoL、SS、FVG、AMD、PoP、EQ、NWOG、NDOG、HTF/LTF、MTF、IRL/ERL、IFVG/ICiSD、PD array、R:R、SL/BE、C1/C2/C3/C4 等），首次出现时附中文注释，后续直接沿用；描述性术语译为中文（摆动点、失败摆动、受保护摆动、位移、关键位、扩张、盘整、回撤、反转、延续等）。完整口径见 `glossary.md`。
- **社区观点**：每章各小节下的 Community insights 以"社区观点"小节 + 引用块呈现；出处行（如 `Garrett — "4H Profiling", 43:20 ↗`）逐字保留，含 ↗ 符号与时间戳，无 ↗ 的按原文。
- **结构**：每章保留原文章号与小节编号（如 6.1 / 6.2）、In brief、Questions this chapter answers 及正文层级。
- **已知局限**：
  - 第 13 章（Timeframe Reference）原文为纯周期对照表，无编号小节。
  - 第 18–20 章原文未收录 Community insights（抓取全文确认）。
  - Walkthrough 页为交互式单页应用，静态抓取仅得到首屏外壳，完整判定逻辑与 Decision Tree 页一致。
  - 站点页面底部 Previous / Next 导航未收录；本站其他非笔记页面（如免责声明、致谢）已单独收录。
