# 13. 周期参考（Timeframe Reference）

> **来源**：https://nixtrades.com/notes/13-timeframe-reference/ ｜ **维护者**：Nix Young ｜ **阅读时长**：1 分钟
> 注：Community insights 为署名社区评论（非逐字笔记），出处按原文保留。

| 周期（Timeframe） | 功能（Function） |
|---|---|
| Daily（日线） | DoL（Draw on Liquidity，流动性抽取目标）识别；判断价格将走向哪里 / 正在交易离开什么 |
| 6h / 4h | Profiling（形态刻画）；日线逻辑对齐；脱钩（decoupling）/ 重新同步（re-sync） |
| 4h / Daily | 配合 SMT（Smart Money Technique 背离）的缺口命中 |
| 90m | 10:30 重新同步 / 新开盘参考；首选入场时间窗口 |
| 4h / 6h 开盘 | 更干净入场与扩张确认的首选时间窗口 |
| 15m / 30m / 1h | SS（Strength Switch，强弱切换）确认、PSP（精准摆动点）、SSMT（序列 SMT）；干净的价格行为确认 |
| 3m / 5m | CiSD（Change in State of Delivery，交付状态改变）/ FVG（公允价值缺口）入场触发 |

补充规则：

- SS 确认日线 ERL（区间外流动性）/ IRL（区间内流动性）。
- Universal Sequence（通用序列）确认日内延续。
- 纽约（NY）交易者：如果 DH / DL（日线高 / 低点）在亚洲 / 伦敦时段形成，用 30m / 1h CiSD 确认。
- 非纽约交易者：15m / 30m CiSD 即足够。
- 15m 可在 10:30 之前使用。
