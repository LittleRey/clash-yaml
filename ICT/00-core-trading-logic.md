# 0. 核心交易逻辑总览（Core Trading Logic Overview）

> **来源**：https://nixtrades.com/notes/00-core-trading-logic/ ｜ **维护者**：Nix Young ｜ **阅读时长**：6 分钟
> 注：Community insights 为署名社区评论（非逐字笔记），出处按原文保留。

## 概述（Overview）

本框架的核心在于：不要把 SMT、FVG、CiSD 或时间窗口当作孤立的信号。它们应当组合起来使用，以回答四个问题：

1. **当前的价格叙事（price narrative）是什么？**
   - 周线（weekly）K 线大概会走向哪里？
   - 日线（daily）K 线大概会走向哪里？
   - 当前 4h / 6h K 线大概会走向哪里？
   - 我交易的是反转（reversal）还是延续（continuation）？

2. **价格是否已经到达一个关键的流动性抽取目标（Draw on Liquidity）？**
   - 日线高点 / 低点
   - 周线 EQ（Equilibrium，均衡）/ 前一周 EQ
   - NWOG（新周开盘缺口）/ NDOG（新日开盘缺口）
   - HTF（高周期）缺口
   - HTF 摆动高 / 低点
   - 区间边界 / 区间内部关键位

3. **相关性资产（correlated assets）是否已同步？**
   - 是否存在 SMT？
   - 是否存在 SS（Strength Switch，强弱切换）？
   - 领先资产（leading asset）是否已到达抽取目标？
   - 滞后资产（lagging asset）是否仍需追赶？
   - 资产是否处于脱钩（decoupling）/ 重新同步（re-sync）阶段？

4. **是否有足够的位移（displacement）确认？**
   - CiC（相关性破裂）/ CiSD（交付状态改变）
   - FVG（公允价值缺口）
   - PSP（精准摆动点）
   - Driver（驱动事件）扩张
   - 1h / 90m / 4h K 线是否支持延续

## 0.1 底层因果链（Underlying Causal Chain）

这个模型可以理解成一条从"抽取目标"到"执行"的因果链：

1. **市场需要低阻力（low-resistance）的抽取目标才能扩张 → Draw on Liquidity（流动性抽取目标）**
   - 市场要扩张，首先必须存在低阻力抽取目标。
   - 抽取目标包括高 / 低点和 FVG。
   - 理想的抽取目标是低阻力流动性。
   - 低阻力抽取目标通常是失败摆动（failure swing）。
   - 高阻力抽取目标通常是受保护摆动（protected swing）。
   - 除非有特殊确认，否则不要直接交易进受保护摆动。
   - 没有清晰的抽取目标，就不要强行预测扩张。

2. **市场需要摆动形态（swing formation）才能反转 → Profile（形态）**
   - 市场要反转，必须先出现有效的摆动形态。
   - 摆动形态是反转形态（reversal profile）的基础。
   - 首选形态是带小日线影线的 AMD（Accumulation, Manipulation, Distribution，积累—操纵—派发）。
   - 在猎杀破坏（seek-and-destroy）条件下，交易极端位。
   - 在区间盘整（range consolidation）中，SMT 通常会验证失败摆动。

3. **摆动形态的形成需要关键位 → Key Level（关键位）**
   - 高质量摆动通常从关键位形成。
   - 日线高 / 低点通常也从关键位形成。
   - 有效的关键位就是相关摆动（relevant swing）。
   - 例外：带 SMT 的失败摆动即使不是经典关键位，也可作为有效的反转参考。

4. **相关性破裂（Crack in Correlation）验证从关键位形成的摆动形态 → CiC**
   - CiC（如 SMT / SSMT / PSP）验证从关键位形成的摆动。
   - 没有 CiC，摆动质量较低。
   - CiC 确认倾向（bias）；它本身不创造倾向。
   - 有效的 SMT 应当出现在关键位。

5. **CiC 之后的反转信号（reversal signature）确认扩张正在发生 → LTF 反转信号**
   - SMT / SS 之后，必须有 LTF（低周期）反转信号。
   - 真正的扩张确认来自位移 / 缺口 / CiSD。
   - 优先选择实体粗壮的 CiSD（bulky-bodied CiSD）。
   - 如果干净的 CiSD 距离太远，可以用失败摆动 CiSD 作为执行触发。

简化公式：

**抽取目标 → 关键位 → 摆动形态 → 相关性破裂 → 反转信号 → 扩张**

## 0.2 日内流程（Daily Procedure）

每日工作流：

1. **日线（Daily）**
   - 决定今天价格大概会走向哪里。
   - 决定价格正在交易离开什么。
   - 识别主要 DoL 和邻近的抽取目标。

2. **将日线逻辑与 4h / 6h Profiling 对齐**
   - 用 4h / 6h K 线形态判断当前交易时段（session）是否支持日线叙事。
   - 如果日线逻辑与 4h / 6h profiling 不一致，降低交易优先级。

3. **在干净的 30m / 1h 价格行为上交易**
   - 等待干净的 30m / 1h 价格行为。
   - 当多周期（MTF）价格行为混乱时，不要强行降级到 LTF 执行。
   - LTF 只用于入场触发；它不替代 HTF 叙事。

## 0.3 价格阶段（Phases of Price）

### 社区观点（Community insights）

> **Garrett — Anomaly Course: Phases of Price, 3:31**
>
> 猎杀破坏（seek-and-destroy，一种扩散/展开形态）属于盘整而非反转：如果区间远端仍有未被抽取的目标，价格可以操纵近端，纯粹为了推动行情穿越回远端。由于盘整无法反转，一旦这个过程走完，就可以交易价格回到原始方向。

> **Garrett — Anomaly Course: Phases of Price, 2:29**
>
> 回撤触及前一根 K 线区间的 EQ——尤其在一个上涨腿（bullish leg）内跌入深度折价——是"该腿可能并非真正的扩张"的危险信号。真正的扩张腿保持浅回撤，根本不需要触及 EQ。

> **MMXM Trader — High Time Frame Bias, 5:21 ↗**
>
> 市场形态只在关键时间点改变——在最高周期上，就是新季度。当连续两个季度印出相同的市场形态（例如都是积累）时，预期下一个季度会异常抛物线性、单边运行、几乎不回撤，而不是认为均值回归即将到来。

> **Lathyrus Masterclass — Examples — Example 1, 1:19**
>
> 整套框架不只是日内/日线工具——同样的反转、回撤与延续机制在月线、周线图上如出一辙；其范例展示了一个月线缺口内的两级 PSP，由周线与日线上的全新 SMT 在价格扩张时确认，所有信号在同一时刻嵌套出现。

正文：每个 PoP（价格阶段）——盘整、回撤、反转——都以扩张开始、以扩张结束。每个阶段都有 if-then 式的结局：

- **盘整 → 延续。** 盘整是延续信号；价格无法直接从盘整中反转。它不一定要操纵盘整的低 / 高点，但在预期扩张真正到来之前，你需要看到一次操纵。
- **回撤 → 扩张。** 真正的回撤在完成后会恢复此前的扩张；它本身不是反转信号。
- **反转 → 扩张。** 一旦价格交易进一个相关关键位并在此印出反转信号，就预期扩张随之而来。

识别各阶段所需信号：

- **扩张（Expansion）**：穿越高点并拒绝低点；尊重对手方 K 线 / FVG；回撤保持浅，不应触及前一根 K 线区间的 EQ，尤其不应在上涨腿内深度折价——深度回撤进入 EQ 是"该腿可能并非真正的扩张"的危险信号。
- **盘整（Consolidation）**：在高点和低点之间区间震荡，两侧形成失败摆动，直到某一侧被触及前不应参与。第二种形式是猎杀破坏（扩散形态）：如果区间远端仍有未被抽取的目标，价格会先操纵近端，纯粹为了推动行情穿越回去操纵远端——这是盘整的一种，不是反转，一旦走完可以交易回到原始方向。
- **回撤（Retracement）**：在回撤点形成邻近高 / 低点（失败摆动），价格行为乏力、低信心；价格通常回扫进一个缺口而不是反转。第二种形式：价格交易进盘整的低 / 高点但未能操纵它——通常是因为区间内其他位置存在一个更高周期的 FVG 才是真正的目标，而不是盘整的极值。
- **反转（Reversal）**：扩张进入一个相关关键位，随后扩张离开它（V 形）。用 CiSD 确认——K 线收盘重新穿回最初扩张进入该位时所创造的对手方 K 线 / 订单块（order block）——理想情况下在同一关键位还伴随 SMT 背离。

在更高周期上，这四个阶段表现为 K 线级别的信号：内包线（inside bar，未能击穿前一根 K 线的高低点）读作 HTF 盘整；一连串邻近高 / 低点读作 HTF 回撤（那些失败摆动 / 低阻力流动性应当被作为目标，而不是远离它们交易）；停留在前一根 K 线收盘范围内的短影线读作 HTF 扩张信号；在关键位形成的 C2（反转）K 线读作 HTF 反转信号。确认 HTF 反转 K 线的方法是降级到更低周期，要求其内部可见同样的 V 形反转信号（一组摆动点序列）——LTF 以确认其他任何反转的同样方式确认 HTF K 线。
