# 决策树（Decision Tree）

> **来源**：https://nixtrades.com/decision-tree/

本决策树由 `trading_study_notes_integrated.md` 压缩而成。

设计原则：

1. 任何 Layer 0 命中都意味着立即放弃；不要继续往下走。
2. 所有 Layer 1 硬性门槛全部通过才允许交易。评分只决定仓位大小；它不决定是否存在一笔交易。
3. 标注 ⚠️ 的项目目前只有主观定义。它们需要书面标准加上正反图例，才可执行。
4. 原始笔记中只保留了两条例外路径：Branch R 第 3 项和 G3 注。其余所有例外均已删除。

## 运行流程（Runtime flow）

决策树运行流程：新 K 线或新交易时段开始。Layer 0 止损开关扫描：任何命中都意味着不交易，等待下一个时间窗口。否则进入 Layer 1 硬性门槛 G1 至 G6：任何一项为否都意味着不交易。否则 Layer 2 资产路由选择分支——反转（Reversal）、延续（Continuation）或失败摆动（Failure Swing）；所有分支条件必须全部满足。否则进入 Layer 3 质量评分：3 分及以下放弃，4 到 6 分半仓风险，7 分及以上标准风险。然后 Layer 4 执行与管理：止损、保本、反转最多两次机会。

Layer 0（止损开关）→ Layer 1（硬性门槛 G1-G6）→ Layer 2（路由：反转 / 延续 / 失败摆动）→ Layer 3（质量评分）→ Layer 4（执行与管理）。

## Layer 0：止损开关（Kill switches，任一命中 = 不交易）

### K1：C4+ K 线
条件：当前 K 线是 C4+。
动作：等待一个新序列。

### K2：DoL 已被触及
条件：DoL（流动性抽取目标）已经被触及。
动作：等待新的 DoL 形成。

### K3：回撤越过 EQ
条件：价格已经回撤越过 EQ（均衡）。
动作：反转叙事失效。

### K4：双重扫掠（Double sweep）
条件：双重扫掠。
动作：放弃。不要采取低概率例外。

### K5：当前 MTF K 线带大影线
条件：当前 MTF（多周期）K 线带有大影线。
动作：4h 大影线则等待新的 6h 开盘；6h 则等待 4h；1h 则等待 90m；90m 则等待 1h。

### K6：临近驱动事件
条件：价格非常接近一个驱动事件（driver）。
动作：等待驱动事件本身给出结构。

### K7：临近伦敦 9:00
条件：价格在伦敦 9:00 附近。
动作：等待价格行为稳定下来。

### K8：日线逻辑与 4h/6h 形态冲突
条件：日线逻辑与 4h/6h 形态不一致。
动作：站在一旁不做。

### K9：高阻力抽取目标
条件：抽取目标是高阻力的，即一个受保护摆动（protected swing）。
动作：不要朝受保护摆动方向交易。

### K10：极端隔夜或 10am 前扩张
条件：已经发生非常大的隔夜扩张，或 10am 前形成了一个极端区间且 DoL 已被取走。
动作：不要强行做 10am 延续。

## Layer 1：硬性门槛（Hard gates，六项全部必须为是）

### G1：清晰的 DoL
标准：目标属于预定义清单：日线/周线高/低点、前一周 EQ、日线 EQ、NWOG/NDOG、HTF 缺口、区间边界、内部位；且它是低阻力的、失败摆动型流动性。
状态：⚠️ 低阻力需要书面定义。

### G2：关键位被触及
标准：价格已到达一个预定义关键位：4h+ 缺口、1h+ 摆动高/低点、1h 订单配对区间、NWOG/NDOG、日线/周线高/低点。
状态：可客观化 ✅。

### G3：关键位上的 CiC
标准：SMT / SSMT / PSP 出现在 G2 关键位。唯一保留的例外：失败摆动 + SMT 可替代经典关键位，但它必须走 Branch F。
状态：⚠️ "大致同一时间"需要定义。建议起点：同一根 LTF K 线之内。

### G4：LTF 反转信号
标准：位移 / 缺口 / CiSD 至少出现其一，且 CiC 在前、信号在后。顺序不可颠倒。
状态：可客观化 ✅。

### G5：干净的 30m/1h 价格行为
标准：书面标准仍需补充。建议起点：最近 N 根 K 线内无双重扫掠、无连续重叠区间、无未回补的双向缺口。
状态：⚠️ 必须先定义。

### G6：RR 达到阈值
标准：到最近抽取目标的 RR ≥ **2.0**。这是占位值，待用蒙特卡洛结果修订。SL（止损）由 SMT 失效位计算。
状态：可客观化 ✅。

## Layer 2：路由（Routing）

### 2.0 资产路由（先选资产，再选分支）

```
哪个资产最接近 DoL 且 RR 仍可接受？-> 交易该资产（领先）

领先资产是否已取走抽取目标？-> 切换到滞后资产（多资产时优先中间；不要用最弱的）

SS 是否刚刚发生？-> 只交易新的领先资产；旧的领先/滞后逻辑作废

资产已脱钩且无 SS？-> 不交易；等待 SS 或两级 PSP

                              （PSP 用 6:00 4h 收盘，重新同步用 10:00 4h，
                              若失败，则 10:30 / 新的 90m）

ES 是领先？-> 降级处理（原始笔记：通常不理想）
```

### Branch R：反转（Reversal）
入场前所有条件必须全部满足：

1. G1-G6 已通过，且 DoL 已被触及，或价格处于一个 HTF 关键位。
2. **两级 SMT** 或 **SMT + PSP** 在场。这是最高概率结构。
3. **SS 出现**。如果没有 SS，则所有相关资产必须同时呈 V 形；否则放弃。
4. 位移 / 缺口确认该动作。
5. 入场：**第二根 CiSD**。唯一的早入场条件是第一根 CiSD 呈 V 形且强烈位移。
6. 15m 缺口只能在折价区用于早反转。溢价区的 15m 缺口绝不能作为反转依据。
7. 当 HTF 4h+ SMT+PSP 有效时，不需要额外的 LTF SMT。

### Branch C：延续（Continuation）
入场前所有条件必须全部满足：

1. 趋势清晰，日线高/低点已形成，且价格在日内区间之内。
2. 出现盘整，**一侧已被扫掠**，且对侧内部位尚未被操纵。
3. 缺口 / FVG 形成。**近期缺口：一级 SMT 即可。陈旧缺口：需要两级。**
4. 入场：缺口回测，**第一根 CiSD**。
5. 周期规则：早段用 15m+；晚段延续用 30m+。
6. 如果 C2 已经扩张，不要交易 C3。
7. 目标：原始 DoL / 区间边界。

### Branch F：失败摆动（Failure Swing，唯一保留的例外通道）
**三要素缺一不可：失败摆动 + SS + 离开的缺口。**
只有当理想 CiSD 太远时，才可用失败摆动 CiSD 作为触发。
任何一个要素缺失，回到"不交易"。

### Branch D：驱动事件判断（叠加在 R/C 之上，不是独立的入场理由）

| 驱动事件前的状态 | 预期 |
|---|---|
| 驱动事件前反转已形成 | 驱动事件延续 |
| 反转尚未形成 | 驱动事件反转 |
| 驱动事件未能反转 | 反转失效，然后寻找延续 |
| 回撤进缺口未能反转 | 从驱动事件扩张；驱动事件 = 扩张定时参考 |
| 驱动 K 线形成 PSP | 基于时间的 CiC，评分 +2 |

## Layer 3：质量评分（Quality score）

### SS 出现
分值：**+2**。最高优先级共振。

### 驱动 K 线形成 PSP
分值：**+2**。基于时间的 CiC。

### 入场接近新开盘
分值：+1。入场接近一个新的 90m / 4h / 6h 开盘。

### 带缺口的 CiSD
分值：+1。最佳 CiSD。

### 实体粗壮的 CiSD
分值：+1。⚠️ 需定义。建议起点：实体 ≥ 整根区间的 70%。

### SMT 高/低点在同一根 LTF K 线内
分值：+1。

### 两级 PSP
分值：+1。

### 带小影线的 AMD
分值：+1。日线形态为 AMD + 小影线。

### 扩张后的缺口
分值：+1。延续质量。

### 正确的 P/D 位置
分值：+1。折价做多 / 溢价做空；仅在回撤 PoP 期间计分。

**仓位档位（风险金额遵循账户管理模块，起点 \$300/笔）：**

| 总分 | 档位 |
|---|---|
| ≥ 7 | A：标准风险 |
| 4-6 | B：半仓风险 |
| ≤ 3 | C：放弃，即使所有门槛都已通过 |

## Layer 4：执行与管理（Execution and management）

1. SL：放在 SMT 失效位之外 / 反转 K 线极值之外。
2. 入场后按计划移到 BE（保本）。偏好早入场，因为保护成本更容易。
3. **每次反转最多两次机会**：第一次，从摆动点直接扩张；第二次，C2 摆动被操纵后反转。如果两次都失败，反转即失效。然后只寻找延续/失效入场，用整体 DoL 内最近的内部位作为失效点。
4. 移动止损：仅在通用序列（universal sequence）下使用。扩张后，用第一根 CiSD EQ 折价/溢价内部的影线作为移动 SL。
5. 加仓：仅当第一笔仓位在第一根 CiSD 入场时，才考虑在第二根 CiSD 加仓。
6. 回撤/考核账户：必要时在 2R 出场，若价格行为允许再入场。实盘账户：到 BE 后，等待完整 TP 或 BE。
7. **犹豫 = 不入场。**
